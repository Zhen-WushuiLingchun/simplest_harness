## Cache 成本判断

DeepSeek 官方说明 context cache 默认开启，命中需要完整匹配已持久化的前缀，且
best effort、不保证 100%。这 80 个公开 trial 的观测命中率接近 99.5%，原因主要是
同一长轨迹内后续请求重复之前的完整对话前缀；它不要求 20 个仓库彼此共享仓库内容。

按冻结时官方价格，Flash 每 1M cache-hit input 为 `0.0028 USD`、cache-miss input
为 `0.14 USD`、output 为 `0.28 USD`。但 TMSH 当前事件未记录 hit/miss 字段，故只能
把公开 `9.274355428800000363 USD` 当作对照成本，不能将其写成 TMSH 的实际费用。

如果仅为预算规划而把公开子集的 cache-hit fraction 套到已经观测的四个有效 anko
TMSH trial（input `90463906`、output `636700`），得到 4 次约
`0.4940644084106119998730706289 USD`、80 次约
`9.881288168212239997461412578 USD`。这是明确标注的外推，不是账单或正式结果。
